## 测试约定

### 优先级定义
| 级别 | 含义 | 通过标准 |
|------|------|---------|
| P0 | 阻断级 — 核心链路不可用 | 100% 必须通过 |
| P1 | 严重 — 主要功能异常 | 100% 必须通过 |
| P2 | 一般 — 次要功能异常 | ≥95% 通过 |
| P3 | 轻微 — UI/体验问题 | ≥90% 通过 |

### 前置条件
- 测试设备已安装 PoseAI v2.2.1 APK
- 设备已连接网络（内购/OOTD 在线分析需要）
- 设备摄像头可用
- 设备存储空间 ≥ 500MB
