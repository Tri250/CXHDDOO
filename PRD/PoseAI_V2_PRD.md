# PoseAI V2 宏大升级产品需求文档 (PRD)

## 一、 产品背景与目标 (Background & Goals)
随着 PoseAI V1.0（基础出片与场景分类）和全量代码安全加固的完成，项目已达到极其稳定的生产级别。V2 的核心是在**稳定地基上搭建护城河**，实现从“机械参数计算”向“感性美学指导和内容沉淀”的跃迁。
V2 目标是进一步拉开竞品差异化，提高用户长期开启和留存的核心率。

## 二、 核心功能规划 (Core Features)

### 1. 🎨 审美升维：CIFilter 电影级调色引擎 (Filter Engine) 
*在现有原图直出的基础上，提供真正具备“一键大片感”的质感滤镜，降低用户出图的废片率，打通分享欲流转。*
*   **功能需求**：集成上一阶段已测试走通过的 `PhotoFilterEngine`。在 Vlog 预览或单张照片回看 (`PhotoPreviewView` / `VideoPreviewView`) 时新增 4 套高级预设（胶片、黑白、日系清透、赛博霓虹）。
*   **性能要求**：利用 `CIContext` GPU 硬件渲染，百毫秒级无缝切换；滤镜操作全部基于非破坏性（Non-destructive）缓存。
*   **交互效果**：滑动或底部横向 ScrollView 选择滤镜。切换带有微小震动反馈。

### 2. 🧠 数据沉淀核心：SwiftData 本地持久化 (Persistence)
*为用户提供极具成就感的“拍摄长廊”，记录所有的光影瞬间，留住回忆。*
*   **实体设计**：
    *   `ShootingRecord`: 记录每次成功产出的照片/Vlog、发生场景 (SceneType)、关联滤镜、时间戳与拍摄地（预留位置信息）。
*   **视图集成**：
    *   首页入口：原先 mock 数据的 Gallery 需要替换为查询 SwiftData 持久层。
    *   回忆回溯：支持按时间段（月份/日期）流式浏览。
*   **衍生价值**：后续版本可依赖此数据表制作“年度影集报告”与“个人偏好姿态”统计图表。

### 3. 🤖 模型进阶：GPT-Vision 视觉流体多模态接入 (AI Brain)
*在断网版预设词引擎稳定后，接入正版的云端大模型，将产品的“聪明度”推上神坛。*
*   **场景描述**：将抽取的帧（含 OOTD 内容）+ 当前相机硬件返回的光线参数 + GPS定位 等上下文，通过 API 请求传给真正的 Vision 大模型。
*   **并发要求**：为了不阻塞拍摄，网络请求需置于单独 Task 并允许超期（10秒）降级为离线模式。

## 三、 分期迭代计划 (Phases)

| 迭代包 | 模块 | 预估工时 | 里程碑界定 |
| --- | --- | --- | --- |
| **V2-Sprint-1** | CIFilter 滤镜 UI 集成 | 1.5 天 | `PhotoPreviewView` 可实时切换4种质感大片并保存至相册。 |
| **V2-Sprint-2** | SwiftData 数据持久化搭建 | 2 天 | `GalleryView` 可读取和显示自 App 安装以来的全部实际成品。 |
| **V2-Sprint-3** | GPT 真实云端网络对接 | 2.5 天 | OOTD 提示词获得质的飞跃，真实验证断网降级兜底逻辑。 |

## 四、 关键技术债规避
- 在对接 `PhotoFilterEngine` 时，务必确保 `UIImage` 的 EXIF 朝向信息在转换 `CIImage` 间不丢失导致横竖颠倒。
- 引入 `SwiftData` 前确保对 `SceneType` 的 Enum 进行原生兼容处理 (`Codable` 兼容)。
